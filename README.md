# CagePlate

A Windows GUI tool for mouse management and genotyping.

## Features
- **Cage to plate**: Prepare a sample table for genotyping on plates (e.g., 96-well), with samples grouped by cage.
- **Plate to cage**: Aggregate per-sample genotypes into per-cage genotype results.
