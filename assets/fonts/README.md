# Section-heading font

`Ubuntu-Bold.ttf` is the unmodified Ubuntu Bold font, Copyright 2011 Canonical Ltd. It is bundled to render actual bold section titles; egui's `RichText::strong()` alone only changes text color.

Source: https://github.com/google/fonts/blob/main/ufl/ubuntu/Ubuntu-Bold.ttf

SHA-256: `679b5c1e09cab3156bb8ef529735f9382bf31ca7ac737382ab959297f8d82ad4`.

The font is distributed under the Ubuntu Font Licence 1.0, included in `UFL.txt`. The licence is also recorded in the font's metadata. Body text retains egui's existing default fonts and fallback glyphs.
